# 📝 ResuMe Studio

A modern and responsive Resume Builder built using HTML, CSS, and Vanilla JavaScript.

Resume Studio is a simple web application that allows users to create a professional resume with a live preview, dynamic projects, skills, and contact information.

---

# ✨ Features

### 👤 Personal Information

* Add Name, Job Title, Email & Phone
* Add LinkedIn & GitHub links
* Write a professional summary
* Real-time live preview

### 💼 Dynamic Projects

* Add multiple projects dynamically
* Add project name, tools & description
* Add GitHub & Live Demo links
* Remove projects
* Automatic project numbering

### 🛠️ Skills

* Add skills using the Enter key
* Display skills as tags
* Remove individual skills
* Automatically update the resume preview

### 👀 Live Resume Preview

* Instant updates while typing
* Automatically renders projects and skills
* Clickable profile and project links
* Clean resume-style layout

### 📄 PDF Export

* Export the resume using the browser's print system
* A4 print layout
* Print-optimized styling

### 📱 Responsive Design

* Responsive form and preview layout
* Works across desktop and smaller screens
* Clean and minimal interface
